# Rubix Defence — Portfolio Site

A single-page, self-contained portfolio for an AI × autonomous-systems defence startup.

- **`index.html`** — the main interactive site: a Three.js 3D drone hero, a light/dark
  sectioned layout, project cards with embedded imagery, and a dedicated detail page
  (overview, applications, use cases, capabilities, spec sheet, concept diagram) per system.
- **`demo.html`** — alternate build that streams real public-domain drone photos/video from
  the web (open it in a browser; not needed for `index.html`, which embeds its own images).

## Systems featured
Simulation — War Simulator, Artillery Simulator · Perception & SA — DRISHTI, GeoVision,
OSINT Recon · Sovereign Stack — RASAD, NIRIKSHAK · Drones — Swarm, Surveillance UAV,
Logistics, Drone-Drop Correction · Manufacturing — 3D Printing & Prototyping.

## Run / host
`index.html` is fully self-contained (images are embedded; only Three.js loads from a CDN).
Open it directly, or enable **GitHub Pages** (Settings → Pages → deploy from branch) to host it.
